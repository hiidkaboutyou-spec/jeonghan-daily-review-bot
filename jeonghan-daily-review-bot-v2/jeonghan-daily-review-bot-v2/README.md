# Jeonghan Daily Review Bot v4.0

دستیار خصوصی و Review-only کانال دیلی یون جونگهان. هر خروجی اول برای بررسی به چت خصوصی ادمین می‌آید و هیچ پستی خودکار وارد کانال نمی‌شود.

## قابلیت‌های اصلی نسخهٔ 4

- بازپخش کامل دو ساعت اخیر با دکمهٔ `🕑 همهٔ دو ساعت اخیر`؛ حتی توییت‌هایی که قبلاً دیده شده‌اند دوباره می‌آیند.
- انتخاب هر منبع و دریافت تمام پست‌ها و replyهای ۲۴ ساعت اخیر آن از قدیمی به جدید.
- جست‌وجوی آرشیوی با تاریخ یا توضیح آزاد. بات ابتدا چند رویداد نزدیک پیشنهاد می‌دهد؛ بعد از انتخاب، نتیجه‌های همان رویداد و رشته‌های مرتبط را جمع می‌کند.
- ترتیب قطعی قدیمی‌ترین → جدیدترین، با بخش‌بندی روشن. ترجمه‌های یک لایو بر اساس `conversationId` کنار هم می‌مانند و آپدیت نامرتبط وسطشان نمی‌آید.
- دریافت replyهای منابع تخصصی تا بخش‌های دوم و سوم ترجمهٔ لایو جا نماند.
- بررسی خودکار نام و هشتگ جونگهان به انگلیسی، کره‌ای و ژاپنی در هر اجرای معمول.
- منبع `@couphanfiles` به فهرست اضافه شده است.
- انتخاب بهترین نسخهٔ قابل‌ارسال ویدیو از X، fallback به کیفیت سبک‌تر در صورت بزرگ بودن، fallback دوم با `yt-dlp` و ارسال ویدیو به‌صورت streamable.
- نگهداری تمام مدیاهای یک مجموعه و تقسیم خودکار مجموعه‌های بزرگ به آلبوم‌های پشت‌سرهم.
- موتور تم قطعی: یک لایو/رویداد در تمام پیام‌هایش هدر ثابت دارد؛ اینستاگرام خود جونگهان، اینستاگرام اعضا، خبر، عکس، ویدیو و ریمایندر خانوادهٔ تم جدا دارند.
- اصلاح قطعی راست‌به‌چپ برای هدرهای سیمبل‌دار فارسی با RLM نامرئی و پیشوند `،،`.
- حافظهٔ لحن از ۹٬۲۴۵ الگوی پاک‌سازی‌شدهٔ کانال: ۸٬۶۱۲ پیام فارسی/ترکیبی و ۶۳۳ توالی دوپیامی، با وزن بیشتر برای صدای ۲۰۲۵–۲۰۲۶.

نمونهٔ صحیح RTL:

```text
،، 🐹⌕໋  ִ˒˒ متن فارسی
```

## کار با بات

بعد از نصب، در چت خصوصی بات `/start` را بفرست. دکمه‌های اصلی:

- `🕑 همهٔ دو ساعت اخیر`: بازپخش بدون توجه به Seen بودن.
- `🔎 جست‌وجوی آرشیو`: توضیحت را می‌گیرد، گزینه پیشنهاد می‌دهد و بعد نتیجهٔ انتخابی را کامل جمع می‌کند.
- `🗂 انتخاب منبع ۲۴ساعته`: منبع را انتخاب می‌کنی و خروجی مرتب دریافت می‌کنی.
- `📋 صف درخواست‌ها`: پیشرفت درخواست‌های بزرگ را نشان می‌دهد.

دستورهای معادل:

- `/recent2h`
- `/search توضیح یا تاریخ`
- `/sources`
- `/source24 username`
- `/jobs`
- `/status`
- `/pending`
- `/edit ID درخواست`
- `/cancel`
- `/help`

اگر نتیجه زیاد باشد، هر اجرا حداکثر ۸ پیش‌نویس آن درخواست را تحویل می‌دهد و بقیه در اجراهای بعدی خودکار ادامه پیدا می‌کند. دکمه‌ها در اجرای بعدی GitHub Actions پردازش می‌شوند؛ با برنامهٔ فعلی انتظار معمول حداکثر حدود ۱۵ دقیقه است.

روی هر پیش‌نویس می‌توانی `😂 بامزه‌تر`، `🪽 نرم‌تر`، `📰 دقیق‌تر`، `✍️ ویرایش دلخواه`، `✅ فرستادم` یا `🗑 رد` را بزنی. Reply مستقیم روی کارت بررسی هم ویرایش دلخواه همان پیش‌نویس است.

## نصب خیلی ساده روی Repository فعلی

1. ZIP نهایی را Extract کن.
2. در صفحهٔ اصلی Repository، `Add file → Upload files` را بزن.
3. پوشهٔ کامل `jeonghan-daily-review-bot-v2` را داخل صفحه بکش و Commit کن.
4. در Actions اول Workflow را با `mode: check` اجرا کن.
5. وقتی سبز شد، یک بار با `mode: live` اجرا کن.
6. در تلگرام `/start` را بفرست.

لازم نیست `.github` یا هیچ فایل مخفی را دوباره آپلود کنی. Secretهای فعلی با جایگزینی فایل‌های پروژه پاک نمی‌شوند.

## Secretهای لازم

در `Settings → Secrets and variables → Actions`:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_REVIEW_CHAT_ID`
- `TELEGRAM_ADMIN_USER_ID`
- `X_COOKIE`
- `GEMINI_API_KEY`
- `GROQ_API_KEY` اختیاری برای fallback

مقادیر واقعی را هیچ‌وقت داخل فایل یا Commit نگذار. X فقط محتوایی را می‌تواند برگرداند که برای حساب Reader قابل مشاهده و هنوز در جست‌وجو/تایم‌لاین عمومی در دسترس باشد؛ پست حذف‌شده یا اکانت خصوصی قابل تضمین نیست.

## منطق ترتیب و تم

1. نتیجه‌ها ابتدا بر اساس زمان مرتب می‌شوند.
2. پیام‌های یک conversation یا رویداد در یک گروه می‌مانند.
3. گروه‌ها بر اساس زمان اولین پیامشان چیده می‌شوند.
4. داخل هر گروه قدیمی‌ترین پیام اول است.
5. موتور تم از کلید پایدار رویداد استفاده می‌کند؛ بنابراین وسط یک لایو هدر عوض نمی‌شود.
6. قبل از متن فارسی سیمبل‌دار، RLM و `،،` به‌صورت قطعی اضافه می‌شود.

شمارهٔ `n از total` فقط روی کارت خصوصی است و وارد کپشن آمادهٔ فوروارد نمی‌شود.

## جست‌وجو و منابع X

اجرای معمول علاوه بر پنج منبع تنظیم‌شده، این شناسه‌ها را جست‌وجو می‌کند:

- انگلیسی: `JEONGHAN`, `Yoon Jeonghan`, `#JEONGHAN`, `#YOONJEONGHAN`
- کره‌ای: `윤정한`, `정한`, `#윤정한`, `#정한`, `#세븐틴정한`
- ژاپنی: `ジョンハン`, `#ジョンハン`

در دریافت ۲ساعته و ۲۴ساعته، replyها نیز خوانده می‌شوند. در سرچ آرشیوی، عبارت فارسی با AI به queryهای چندزبانه تبدیل می‌شود، نتیجه‌های `Latest` و `Top` برای پیشنهادها مقایسه می‌شوند و threadهای گزینهٔ انتخابی هم بررسی می‌شوند.

## کیفیت مدیا

- URL عکس‌های X با اندازهٔ `orig` گرفته می‌شود.
- نسخه‌های ویدیو بر اساس bitrate از بهترین به سبک‌تر امتحان می‌شوند.
- اگر URL مستقیم ناقص باشد، `yt-dlp` نسخهٔ MP4 مناسب را امتحان می‌کند.
- سقف امن فعلی: عکس ۹MB، ویدیو ۴۴MB و هر درخواست آلبوم ۴۴MB.
- Telegram در هر آلبوم حداکثر ۱۰ مورد می‌پذیرد؛ بات مجموعه‌های بزرگ را به چند آلبوم تقسیم می‌کند.
- خرابی یک فایل کل کپشن یا بقیهٔ مدیاها را متوقف نمی‌کند و لینک منبع حفظ می‌شود.

## کنترل کیفیت و ایمنی

- تنظیمات پیش از هر اجرای زنده اعتبارسنجی می‌شوند.
- تست‌های آفلاین دکمه‌ها، سرچ آرشیوی، replay موارد Seen، ترتیب live thread، RTL، تم ثابت، fallback کیفیت ویدیو، خطای آلبوم، deduplication، حافظهٔ لحن و حریم خصوصی را پوشش می‌دهند.
- متن X دادهٔ غیرقابل‌اعتماد است و نمی‌تواند دستورهای داخلی مدل را تغییر دهد.
- محتوای دارای ریسک حریم خصوصی نسخهٔ آمادهٔ فوروارد نمی‌گیرد.
- اگر AI موقتاً از دسترس خارج شود، مورد به‌جای گم شدن برای بررسی دستی نگه داشته می‌شود.
- Token، Cookie و API key پیش از نمایش خطا پاک‌سازی می‌شوند.
- صف درخواست‌ها، Seenها و پیش‌نویس‌ها در GitHub Actions Cache حفظ می‌شوند.

بررسی محلی:

```bash
python -m src.bot --check
python -m unittest discover -s tests -v
```

برای بازسازی حافظه از خروجی محلی کانال:

```bash
python tools/build_channel_memory.py result-4.json result-3.json \
  --output data/channel_memory.jsonl \
  --profile-output data/channel_voice_profile.json
```

فایل JSON خام کانال داخل Repository یا ZIP قرار نمی‌گیرد.
