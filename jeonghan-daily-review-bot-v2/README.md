# Jeonghan Daily Review Bot

این نسخه **Review-only** است:

- ربات به کانال تلگرام وصل نمی‌شود.
- ربات لازم نیست ادمین کانال باشد.
- هیچ پستی مستقیماً در کانال منتشر نمی‌شود.
- هر آپدیت جدید X در چت خصوصی ربات، همراه مدیا و کپشن آماده، برای ادمین فرستاده می‌شود.
- ادمین پیام آماده را خودش به کانال فوروارد می‌کند.

## دکمه‌های ربات

- `😂 بامزه‌تر`: کپشن را با هیومر بیشتر بازنویسی می‌کند و نسخه آماده جدید می‌فرستد.
- `✅ فرستادم`: آن پیش‌نویس را انجام‌شده علامت می‌زند.
- `🗑 رد`: پیش‌نویس را کنار می‌گذارد.

## چیزهایی که لازم است

1. یک ربات از `@BotFather`
2. شناسه عددی تلگرام ادمین
3. یک Repository در GitHub
4. یک کلید Gemini یا Groq
5. Cookie یک اکانت فرعی X
6. فهرست اکانت‌های X مورد اعتماد
7. نمونه پست‌های کانال در `style_guide.md`

## Secrets لازم در GitHub

فقط این موارد لازم‌اند:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_REVIEW_CHAT_ID`
- `TELEGRAM_ADMIN_USER_ID`
- `X_COOKIE`
- `GEMINI_API_KEY` اگر provider روی Gemini است
- `GROQ_API_KEY` اگر provider روی Groq است

`TELEGRAM_CHANNEL_ID` لازم نیست.

برای چت خصوصی، معمولاً `TELEGRAM_REVIEW_CHAT_ID` و `TELEGRAM_ADMIN_USER_ID` یک عدد هستند.

## تنظیم منابع X

در `config.yml`، usernameها را بدون `@` وارد کنید و `enabled: true` بگذارید:

```yaml
sources:
  - username: "example_account"
    enabled: true
    require_keywords: true
```

- `require_keywords: true`: فقط پست‌هایی را بررسی می‌کند که نام جونگهان یا کلیدواژه‌های تعیین‌شده را دارند.
- `require_keywords: false`: همه پست‌های آن اکانت را بررسی می‌کند؛ مناسب فن‌بیس کاملاً مخصوص جونگهان.

## جریان کار

1. GitHub Actions هر ۱۵ دقیقه اجرا می‌شود.
2. پست‌های جدید منابع X بررسی می‌شوند.
3. مدل AI ترجمه و کپشن را طبق `style_guide.md` می‌سازد.
4. یک پیام مدیریتی با دکمه‌ها در چت خصوصی می‌آید.
5. پیام بعدی نسخه تمیز و آماده فوروارد همراه عکس یا ویدیو است.
6. ادمین همان پیام تمیز را دستی به کانال فوروارد می‌کند.

## نکات امنیتی

- Token ربات، کلید API و Cookie اکانت X را داخل فایل‌ها یا چت عمومی قرار ندهید.
- برای X از اکانت فرعی استفاده کنید.
- Repository عمومی است؛ پس `style_guide.md` فقط شامل متن‌های عمومی کانال باشد.
