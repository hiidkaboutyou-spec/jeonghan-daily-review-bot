# 💎 راهنمای جامع و اختصاصی ربات آپدیت‌های یون جونگهان (SEVENTEEN)

این پروژه یک ربات کامل، پیشرفته و بدون باگ برای مدیریت کانال تلگرام سه ساله آپدیت‌های یون جونگهان است. تمام نیازها و مشکلاتی که مطرح کرده بودید به طور کامل در این کد حل شده است.

---

## ✨ قابلیت‌های اصلی ربات

### 1️⃣ حل مشکل راست‌به‌چپ (RTL) و بهم‌ریختگی سیمبل‌ها
* **علت مشکل قبلی:** تلگرام هنگام دیدن متون ترکیبی (فارسی + سیمبل‌های یونیکد مثل `𖥨᩠ׄ݁` یا `،، 🐹⌕໋`) چینش خط را به اشتباه چپ‌به‌راست (LTR) می‌کرد.
* **راه حل:** سیستم از کاراکتر استاندارد `RLM` (`\u200F`) در ابتدای تمام خطوط استفاده می‌کند. این کار باعث می‌شود تمام نمادها و سیمبل‌های برنامه Tumbler دقیقاً در سمت درست قرار بگیرند و ظاهر پست‌ها کاملاً شیک، مرتب و منظم باقی بماند.

### 2️⃣ مرتب‌سازی زمانی دقیق (از قدیمی‌ترین به جدیدترین)
* ربات تمامی آپدیت‌ها و ترجمه‌های لایو (بخش ۱، بخش ۲، بخش ۳ و...) را طبق زمان انتشار واقعی (`created_at`) از **قدیمی‌ترین به جدیدترین** مرتب کرده و سپس به کانال یا ربات می‌فرستد تا ادمین و ممبرها گیج نشوند.

### 3️⃣ دریافت اجباری ۲ ساعت اخیر (`/fetch2h`)
* با زدن دستور `/fetch2h`، ربات تمام آپدیت‌های منتشر شده در ۲ ساعت گذشته را بررسی می‌کند و حتی اگر قبلاً آنها را دریافت کرده باشد، مجدداً کامل و به ترتیب زمانی ارسال می‌کند.

### 4️⃣ دریافت ۲۴ ساعت یک منبع خاص (`/fetch24h @couphanfiles`)
* می‌توانید لینک یا آیدی هر منبعی (مثل `https://x.com/couphanfiles` یا `@couphanfiles`) را بدهید تا تمام آپدیت‌های ۲۴ ساعت گذشته آن منبع را به ترتیب زمانی کامل تحویل بگیرید.

### 5️⃣ موتور جستجوی هوشمند و آرشیو کامل (`/search`)
* **جستجوی تاریخی:** مثلاً با وارد کردن `/search 2024-05-18` تمام آپدیت‌ها، ویدیوها و ترجمه‌های مربوط به آن تاریخ را به صورت کامل و دقیق تحویل می‌دهد.
* **جستجوی توصیفی (بدون تاریخ):** مثلاً اگر بنویسید `/search لایوی که کلاه زرد داشت`، ربات تمام لایوها و رخدادهای مرتبط را با تاریخ به شما پیشنهاد می‌دهد و با انتخاب آن، تمام آپدیت‌های آن موضوع جمع‌آوری می‌شود.

### 6️⃣ جستجوی چندزبانه هشتگ‌ها و اسامی
* چک خودکار اسامی و هشتگ‌های جونگهان به ۳ زبان اصلی:
  * **کره‌ای:** `#정한`, `#윤정한`, `SEVENTEEN 정한`
  * **انگلیسی:** `#JEONGHAN`, `#YoonJeonghan`, `Jeonghan`
  * **ژاپنی:** `#ジョンハン`, `#ハニ`, `ジョンハン`

### 7️⃣ دانلود ویدیوها با کیفیت بالا و مناسب (`yt-dlp`)
* استفاده از کتابخانه `yt-dlp` برای استخراج مستقیم فایل‌های MP4 با بهترین کیفیت و بدون افت کیفیت تلگرامی.

### 8️⃣ قالب‌های تم‌دار یکدست (Themes & Templates)
* قالب‌های مجزا و تثبیت شده برای:
  * 🎙️ **ترجمه لایوها**
  * 📸 **پست‌های اینستاگرام خود هانی**
  * 💎 **پست‌های اینستاگرام سایر اعضا همراه با جونگهان**
  * 💫 **آپدیت‌های عمومی و خبری**

## 🚀 راهنمای نصب و راه‌اندازی گام به گام

### گام اول: دانلود و آماده‌سازی فایل‌ها
تمام فایل‌های پروژه در پوشه `jeonghan_bot` قرار دارند:
* `config.py` - تنظیمات اصلی و قالب‌ها
* `database.py` - پایگاه داده ذخیره‌سازی و آرشیو
* `formatter.py` - موتور تنظیم فرمت RTL و نمادها
* `twitter_fetcher.py` - موتور جستجو و دریافت توییتر/ایکس
* `media_downloader.py` - دانلودر هوشمند عکس و ویدیو
* `bot.py` - سورس اصلی ربات تلگرام
* `.env.example` - نمونه فایل تنظیمات

### گام دوم: نصب نیازمندی‌های پایتون
در سرور یا سیستم خود دستور زیر را اجرا کنید:
```bash
pip install -r requirements.txt
```

همچنین برای کیفیت بالای ویدیوها، ابزار `ffmpeg` را نصب کنید:
```bash
# Ubuntu / Debian
sudo apt update && sudo apt install ffmpeg -y

# Mac
brew install ffmpeg
```

### گام سوم: تنظیم فایل `.env`
فایل `.env.example` را به `.env` تغییر نام دهید و اطلاعات خود را وارد کنید:
```env
TELEGRAM_BOT_TOKEN=توکن_ربات_تلگرام
TELEGRAM_CHANNEL_ID=@آیدی_کانال_شما
ADMIN_USER_IDS=آیدی_عددی_تلگرام_شما

TWITTER_USERNAME=نام_کاربری_توییتر
TWITTER_PASSWORD=رمز_عبور_توییتر
TWITTER_EMAIL=ایمیل_توییتر

AI_API_KEY=کلید_API_جمینای_یا_اوپن_ای_آی
AI_PROVIDER=gemini
```

### گام چهارم: اجرای ربات
برای اجرای ربات دستور زیر را بزنید:
```bash
python3 bot.py
```
