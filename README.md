# بات خصوصی بررسی آپدیت‌های یون جونگهان

این پروژه از صفر و با ساختار یک‌لایه ساخته شده است. هیچ فایل اجرایی موازی، پوشهٔ تودرتوی `v2/v2` یا نتیجهٔ ساختگی ندارد.

## کاری که انجام می‌دهد

- اسکن منابع مشخص‌شده در `config/sources.json`
- اسکن نام و هشتگ جونگهان به انگلیسی، کره‌ای و ژاپنی
- دکمهٔ «دو ساعت اخیر» که حتی موارد قبلاً دیده‌شده را دوباره می‌فرستد
- دریافت کامل ۲۴ ساعت یک منبع، از قدیمی‌ترین به جدیدترین
- سرچ با تاریخ `2026-07-14` یا `260714`
- سرچ با توضیح فارسی و نمایش حداکثر ۸ پیشنهاد واقعی
- جمع‌کردن thread و بخش‌های مرتبط رویداد انتخاب‌شده
- گروه‌بندی لایوها و جلوگیری از افتادن آپدیت نامرتبط وسط آن‌ها
- دانلود عکس با اندازهٔ اصلی و انتخاب ویدئوی MP4 مناسب
- fallback دانلود ویدئو با yt-dlp و فشرده‌سازی با FFmpeg
- تولید کپشن بر اساس حافظهٔ واقعی کانل
- تم ثابت برای هر رویداد و رعایت راست‌به‌چپ سیمبل‌های فارسی
- ارسال فقط به چت خصوصی بررسی؛ بدون انتشار خودکار در کانال عمومی

## فایل‌های مهم

- `app/` کد اصلی بات
- `config/sources.json` منابع و کلیدواژه‌ها
- `config/themes.json` تم‌ها و سیمبل‌ها
- `data/channel_memory.jsonl` نمونه‌های پاک‌سازی‌شدهٔ لحن کانل
- `data/channel_voice_profile.json` خلاصهٔ قواعد لحن
- `.github/workflows/main.yml` اجرای خودکار GitHub Actions
- `.state/state.json` حافظهٔ Seen، صف، سرچ و پیش‌نویس‌ها؛ توسط Actions Cache نگه‌داری می‌شود

## Secrets لازم

در `Settings → Secrets and variables → Actions` این پنج Secret باید وجود داشته باشند:

- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_ADMIN_USER_ID`
- `TELEGRAM_REVIEW_CHAT_ID`
- `X_COOKIE`
- `GEMINI_API_KEY`

مقادیر واقعی را داخل فایل‌ها ننویس.

## تست داخلی

Workflow قبل از هر اجرای واقعی این دو دستور را اجرا می‌کند:

```bash
python -m app --check
python -m unittest discover -s tests -v
```

## اضافه‌کردن منبع بعدی

فقط یک مورد مشابه زیر به آرایهٔ `sources` در `config/sources.json` اضافه می‌شود:

```json
{
  "handle": "username_without_at",
  "label": "نام نمایشی",
  "enabled": true,
  "priority": 30,
  "include_replies": true
}
```

هشتگ‌های چندزبانه جداگانه باقی می‌مانند و با اضافه‌شدن منبع حذف نمی‌شوند.
