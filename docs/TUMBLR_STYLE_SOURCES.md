## Intended use

Extract reusable visual grammar only, such as:

- symbol families and separator combinations;
- title/header structures;
- spacing and indentation patterns;
- date/source label formatting;
- compact vs decorative layouts;
- theme/mood patterns;
- aesthetic combinations suitable for channel posts.

Do not clone distinctive creator wording or copy long captions verbatim.

## Priority rule

Final style generation should obey this evidence hierarchy:

1. explicit admin corrections and instructions;
2. final admin-approved/posted channel content;
3. historical channel corpus;
4. repeated context-specific preferences;
5. distilled patterns from these Tumblr sources;
6. generic model creativity.

Tumblr inspiration must never silently override established admin/channel preferences.
